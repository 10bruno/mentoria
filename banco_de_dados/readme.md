# Bancos de Dados: Relacional e NoSQL

Material sobre os principais modelos de bancos de dados, suas características, diferenças e os critérios que devem orientar a escolha da tecnologia mais adequada para cada contexto.

O conteúdo parte dos fundamentos de bancos relacionais e NoSQL, passa por conceitos de distribuição e consistência e conecta esses conhecimentos a tecnologias utilizadas no mercado.

## Conteúdo

- Bancos de dados relacionais e NoSQL
- Principais modelos NoSQL
- Diferenças e trade-offs entre os modelos
- Replicação e particionamento de dados
- Consistência e transações
- CAP e PACELC
- Oracle, PostgreSQL, MongoDB, Redis e DynamoDB
- Critérios para escolha de um banco de dados

## Objetivo

Fornecer uma visão prática para entender como diferentes bancos resolvem diferentes problemas e quais critérios devem ser considerados na escolha de uma tecnologia.

> Comece pelo problema. Entenda os trade-offs. Só então escolha a tecnologia.
