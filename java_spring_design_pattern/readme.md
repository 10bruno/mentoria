# Desenvolvimento Backend — Java, Spring e Design Patterns

Material introdutório sobre desenvolvimento backend com Java, explorando os fundamentos da plataforma, o ecossistema Spring e a aplicação de Design Patterns na construção de software.

O conteúdo apresenta como essas tecnologias e conceitos se conectam, destacando boas práticas de organização, manutenção e evolução do código, sem aprofundar aspectos específicos de implementação.

## Conteúdo

- Visão geral do funcionamento de uma aplicação backend
- Java: linguagem, plataforma e ecossistema
- Compilação, bytecode, JDK e JVM
- Desenvolvimento Java com e sem frameworks
- Spring Framework, Spring Boot e seu ecossistema
- Estrutura e componentes de uma aplicação Spring Boot
- Inversão de Controle (IoC) e Injeção de Dependências (DI)
- Acoplamento, coesão e organização do código
- Conceitos e aplicações de Design Patterns
- Padrões Singleton, Factory, Strategy e Observer
- Exemplo prático de refatoração utilizando padrões
- Critérios para escolher abstrações e evitar complexidade desnecessária

## Objetivo

Fornecer uma visão conceitual e prática sobre o desenvolvimento backend com Java e Spring, demonstrando como frameworks e padrões de projeto podem contribuir para aplicações mais organizadas, testáveis e preparadas para evoluir.

> **Bons projetos não são aqueles que utilizam mais padrões ou abstrações, mas aqueles que resolvem problemas reais com a menor complexidade necessária.**
